Learn NANI in 60 seconds

K-means is only as good as where it starts. Watch it roll the dice, then let NANI pick the starting points, and get the same answer every time.

1Make some data

A thousand points in seven groups, the same synthetic set as Fig. 2 of the NANI paper. With your own trajectory, use any array of shape (frames, features).

from sklearn.datasets import make_blobs

data, true_labels = make_blobs(n_samples=1000, centers=7,
                               n_features=2, random_state=0)

2Try plain k-means

Standard k-means starts from random seeds (k-means++). Roll it a few times: most runs are fine, but some merge two groups and split another.

from sklearn.cluster import KMeans

km = KMeans(n_clusters=7, init='k-means++', n_init=1)
labels = km.fit(data).labels_

Across 100 random seeds, 23 gave a visibly wrong answer on this data.

3Let NANI pick the seeds

NANI ranks the points by how central they are and picks starting points from the densest regions, deterministically. Then k-means runs once, from there.

from mdance.cluster.nani import KmeansNANI

nani = KmeansNANI(data=data, n_clusters=7, metric='MSD',
                  N_atoms=1, init_type='strat_all', percentage=10)
seeds = nani.initiate_kmeans()[:7]

km = KMeans(n_clusters=7, init=seeds, n_init=1)
labels = km.fit(data).labels_

4Run it again

Press it as often as you like. Same seeds, same clusters, every run: no random state to set, and one initialization is enough.

5Use it on your trajectory

The whole recipe, ready to paste. Swap in your own data and number of clusters.

from sklearn.cluster import KMeans
from mdance.cluster.nani import KmeansNANI

nani = KmeansNANI(data=data, n_clusters=7, metric='MSD',
                  N_atoms=1, init_type='strat_all', percentage=10)
seeds = nani.initiate_kmeans()[:7]
labels = KMeans(n_clusters=7, init=seeds, n_init=1).fit(data).labels_
